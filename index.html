    03 — Research

    A first controlled study.

    Applied to one of the five systems, GraphMind: does the citation graph actually help, and by how much?

    GCN, GAT and a feature-only MLP were tuned on validation data only and run with five seeds each on the unchanged Cora split. Each was then retrained on altered graphs. The links add about 24 accuracy points — but only when linked papers share topics.

      1. Finding 1

        The graph adds ~24 points

        GCN 0.823 ± 0.007, GAT 0.817 ± 0.012, MLP 0.583 ± 0.011. Every GNN run beats every MLP run.

      2. Finding 2

        Half the links, most of the value

        Removing 50% of citations at random gives 0.762; 18% of papers are left isolated.

      3. Finding 3

        Who is linked matters

        Random neighbours with the same number of links: 0.301 — worse than no graph. Same-topic links fall from 81% to chance.

      4. Finding 4

        No links ≈ no graph

        Retrained without links: 0.571, level with the MLP. The project’s old 0.678 removed links only after training.

      5. Error analysis

        A silent bug, fixed

        The original checkpoint stored references, so its “best” weights were the last epoch’s. Full report ↗

      6. Limits

        What it does not show

        One dataset, one split, transductive, five seeds. Planned, not done: 20 random splits.
